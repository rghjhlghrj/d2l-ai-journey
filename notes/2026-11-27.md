## 今天学到了什么（3 条）

1. **导数的本质**：瞬时变化率。用数值方法验证了：h 越小，(f(x+h)-f(x))/h 越接近真实导数——书里 f(x)=3x²-4x 在 x=1 处，导数是 2。
2. **切线可视化**：把 f(x) 的曲线和 x=1 处的切线画在同一张图上，切线斜率正好等于导数，"导数=斜率"一下子直观了。
3. **梯度**：多元函数把每个变量的偏导数拼成一个向量。关键直觉：梯度指向函数上升最快的方向，训练模型就是反着走（梯度下降）。

## 最有收获的代码（1 段）

```python
def f(x):
    return 3 * x ** 2 - 4 * x

def numerical_lim(f, x, h):
    return (f(x + h) - f(x)) / h

h = 0.1
for i in range(5):
    print(f'h={h:.5f}, 数值极限={numerical_lim(f, 1, h):.5f}')
    h *= 0.1
```

h 从 0.1 一路缩小到 0.00001，数值极限 1.3 → 1.999999...，逼近真实导数 2。"极限"这个词第一次在我眼前变成数字。
