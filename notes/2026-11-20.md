## 今天学到了什么（3 条）

1. **张量就是多维数组**：标量是 0 维、向量 1 维、矩阵 2 维，深度学习里所有数据（图片、文本、权重）最终都装在张量里。
2. **广播机制**：形状不同的张量做运算时，PyTorch 会自动把长度为 1 的维度"复制扩展"对齐，比如 (3,1) 和 (1,2) 运算得到 (3,2)，不用手写循环。
3. **环境搭建流程**：Git 配置身份 → Python 虚拟环境隔离依赖 → 装好 torch + d2l 就能跑书上全部代码。

## 最有收获的代码（1 段）

```python
a = torch.arange(3).reshape((3, 1))   # 形状 (3,1)
b = torch.arange(2).reshape((1, 2))   # 形状 (1,2)
a + b   # 广播：自动扩展成 (3,2) 逐元素相加
```

之前以为不同形状不能相加，原来广播会自动对齐，写代码能省很多事。
