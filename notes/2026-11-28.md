## 今天学到了什么（3 条）

1. **autograd 的四步套路**：`requires_grad=True` 开始追踪 → 做运算 → `backward()` 自动求梯度 → `x.grad` 取出结果。完全不用手写导数公式。
2. **梯度会累积**：不主动清零，新一次 backward 会把梯度累加到旧值上（实验：y=2xᵀx 求两次，梯度从 4x 变成 8x）。所以训练循环里每轮必须 `x.grad.zero_()`。
3. **no_grad 上下文**：评估/推理时不需要追踪梯度，放进 `with torch.no_grad():` 能省内存、加速。

## 最有收获的代码（1 段）

```python
x = torch.arange(4.0)
x.requires_grad_(True)
y = 2 * torch.dot(x, x)
y.backward()
x.grad   # → tensor([ 0.,  4.,  8., 12.])
```

y=2xᵀx 对 x 求导应该是 4x，x=[0,1,2,3] → [0,4,8,12]，**和手算完全一致**。那一刻感觉"梯度下降"真的可以自己算出来了。
